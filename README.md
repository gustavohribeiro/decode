# SONIQ

Code recreation of the [SONIQ Interactive Studio demo](https://soniq.interactive-studio.io) — same copy, dark visual language, scroll-scrubbed hero, pricing, FAQ, and motion patterns.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Notes

- Built with Next.js, Tailwind CSS, and Framer Motion.
- Product media is sourced from the public Wix/Interactive Studio demo assets.
- The site is a fictional product concept for demonstration purposes.
